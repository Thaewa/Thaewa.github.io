# Thaewa.github.io

Personal portfolio and technical notes focused on embedded systems,
firmware engineering, RTOS behavior, and low-level debugging.

The site is built as a static GitHub Pages project using HTML and CSS.
It also includes a sanitized public case study about investigating a
long-run FreeRTOS hang during an RTOS migration.

## Run locally

From the repository root:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
