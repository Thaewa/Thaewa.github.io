About

The work I enjoy most usually has a messy boundary: part software, part hardware, part timing, part field observation. A train control issue in one country, a factory test system that needs to run faster, a mutex that behaves perfectly until interrupts are disabled, or a microcontroller migration where one alternate function decides the day.

My background is practical first, but I keep a strong interest in operating systems, embedded Linux, high-performance computing, and machine learning. I like ideas that become tools, and tools that help engineers understand what a system is really doing.

Selected Work

RTOS / STM32 / FreeRTOS

A FreeRTOS hang that did not look like a scheduling bug at first

Investigated a long-runtime system stall that led into mutex blocking while interrupts were disabled. The fix came from proving that PRIMASK was masking PendSV during a blocking path, closing the BASEPRI-only hypothesis, and restructuring the code into short snapshot and commit phases around the long-running work. The corrected firmware later passed an eight-hour endurance run without reproducing the hang.

Current Work / Cortex-M / STM32F4

A small RTOS kernel for learning the details that commercial kernels hide

Building a minimalist kernel on STM32F4 with manually initialized thread stacks, a SysTick-driven context switch, round-robin scheduling, an idle task, millisecond delays, and blocking binary semaphores. The next pieces I am working toward are mutexes and priority inheritance, because the interesting bugs usually begin where synchronization meets scheduling policy.

Embedded Control / STM32 / Device Authentication

Device authentication between embedded control devices

Developing and validating an authentication flow between embedded control devices. The work combines firmware integration, secure-device communication, board-level bring-up, and signal validation across multiple hardware interfaces.

Industrial Test Systems / QNX / VxWorks

Making automated firmware validation less slow and less fragile

Built firmware test applications and TCP/IP middleware for industrial test platforms, including Intel Atom/VxWorks and QNX on Zynq-7000. One redesign reduced validation time from about 35 minutes to 32 minutes per unit, which matters when a process repeats all day.

Automotive / Renesas MCU / CAN / LIN

Diagnostic middleware for automotive ECUs

Developed production-grade transport, network, and session layer middleware in C for Renesas microcontrollers, including LIN and CAN diagnostics with MISRA-C discipline and unit tests shaped by automotive safety expectations.

RTOS Debugging

PRIMASK, BASEPRI, and the mutex wait that could not switch tasks

A practical walkthrough of a FreeRTOS migration bug where a task entered a blocking mutex path while PRIMASK was set. The important lesson was not only that PendSV was masked, but also why changing the wrapper to BASEPRI alone would not have fixed the design.
